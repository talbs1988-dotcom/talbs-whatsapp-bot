# העוזר האישי 💛

עוזר WhatsApp אישי שמתחבר ל-Claude Code שלכם. טל בשור · עסק שעובד בשבילך.

## איך מתחילים

העוזר מותקן כשירות ועולה לבד. המסך נפתח מהאייקון **"העוזר האישי"** על שולחן העבודה (הכתובת לבד מציגה שער — הגנה מפני משתמשים אחרים במחשב).

אם צריך להפעיל ידנית — לחיצה כפולה על `start.command` (מק).

## מה יש כאן

- `bot.js` — המנוע
- `index.html` — המסך
- `run.sh` — מפעיל את המנוע מתוך השירות (מוצא את Node גם אם הנתיב השתנה)
- `config.json` — הגדרות (שם, תיקייה, מודל, דרך חיבור, קבוצות)
- `.env` — סודות בלבד (טוקן Green API, מפתח OpenAI). לא משתפים!
- `.ui-key` — מפתח הכניסה למסך. לא משתפים!
- `auth/` — החיבור לוואטסאפ בחיבור דרך כרום. לא משתפים!
- `logs/assistant.log` — הלוג
- `install.sh` / `upgrade.sh` — התקנה ועדכון (מריצים דרך הפורטל, לא ידנית)

## בעיות נפוצות

- **המסך לא נפתח?** לוחצים על האייקון "העוזר האישי" (או `start.command`)
- **לא מקבלים תשובה?** הגדרות ← "בדוק ש-Claude עונה"
- **להחליף מספר?** "🔄 התחבר מחדש" במסך, וסורקים מהטלפון החדש
- **לעדכן גרסה?** `curl -sL https://raw.githubusercontent.com/talbs1988-dotcom/talbs-whatsapp-bot/main/template/upgrade.sh | bash`
