🎭 זהות ותפקיד — מי העוזר שלך

כל מה שהעוזר צריך לדעת עליך ועל העסק יושב בקובץ אחד: מה התפקיד שלו, איך לדבר, מה חשוב, מה אסור. העוזר קורא אותו בכל הודעה. אפשר להעלות קובץ מוכן או לכתוב ולערוך ישירות כאן.

נשמר כקובץ העוזר-שלי.md בתיקיית העבודה. אפשר לפתוח ולערוך אותו גם ישירות במחשב.
📁 על איזו תיקייה העוזר עובד
נפתח חלון בחירה של המחשב — בוחרים תיקייה, וזהו. כל מה שהעוזר ייצור יישמר שם. מומלץ תיקייה ייעודית על שולחן העבודה (למשל "עוזר אישי") — כך העוזר ממשיך לראות גם את כל מה ש-Claude Code כבר יודע עליך.

🟢
כרום — חינמי
סריקת QR, רץ על המחשב שלך. חינם לגמרי (מתנתק לפעמים ומתחבר לבד).

Green API
יציב יותר — לא מתנתק ולא תלוי בדפדפן. ~$12/חודש. דורש חשבון ב-console.green-api.com.
🔒
ענן
שדרוג להמשך — תמיד פעיל בלי המחשב. דורש שרת בתשלום.
בקונסול של Green API: Instances ← ה-instance שלכם ← idInstance ו-apiTokenInstance. הפרטים נשמרים רק על המחשב הזה. אחרי החיבור — ה-QR יופיע במסך הראשי וסורקים אותו כרגיל.
מעבר בין דרכי החיבור מפעיל את העוזר מחדש (כמה שניות). "ענן" — שדרוג להמשך.
🎤 הודעות קוליות (אופציונלי)

רוצים לדבר עם העוזר במקום לכתוב? הוא מתמלל הקלטות דרך OpenAI (Whisper) ועונה כרגיל. זה דורש מפתח OpenAI משלכם — העלות כ-2 אגורות לדקת הקלטה. המפתח נשמר רק במחשב הזה, בקובץ .env — לא במסך ולא בקוד.

איך משיגים: platform.openai.com ← API keys ← Create new secret key. טוענים שם כמה דולרים של קרדיט (Billing). אחרי ההדבקה — "שמירת הגדרות".
👥 קבוצות — העוזר מאזין, לא כותב

בוחרים קבוצות שהעוזר יעקוב אחריהן. הוא שומר את ההודעות שלהן לקובץ בתיקיית העבודה (תיקיית קבוצות), כדי שתוכלו לשאול אותו בצ'אט הפרטי "מה היה היום בקבוצת הצוות?" או "מה סיכמנו עם הלקוח?". העוזר לעולם לא כותב בקבוצה — גם אם מבקשים ממנו. רוצים משהו מתוך קבוצה? כותבים בה עוזר, תסכם — והתשובה מגיעה אליכם בצ'אט הפרטי, לא לקבוצה.

לא מוצאים קבוצה ברשימה? זה קורה (קבוצה חדשה, קהילה, או שהחיבור עוד לא סנכרן אותה). שולחים בה הודעה כלשהי (או מחכים שמישהו יכתוב שם), לוחצים שוב "טען את רשימת הקבוצות" — והיא תופיע, מסומנת "נראתה בהודעה". עוד לא נבחרו קבוצות.
