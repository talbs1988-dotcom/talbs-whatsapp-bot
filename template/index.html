🎭 זהות ותפקיד — מי העוזר שלך

כל מה שהעוזר צריך לדעת עליך ועל העסק יושב בקובץ אחד: מה התפקיד שלו, איך לדבר, מה חשוב, מה אסור. העוזר קורא אותו בכל הודעה. אפשר להעלות קובץ מוכן או לכתוב ולערוך ישירות כאן.

נשמר כקובץ העוזר-שלי.md בתיקיית העבודה. אפשר לפתוח ולערוך אותו גם ישירות במחשב.
📁 על איזו תיקייה העוזר עובד
נפתח חלון בחירה של המחשב — בוחרים תיקייה, וזהו. כל מה שהעוזר ייצור יישמר שם. מומלץ תיקייה ייעודית על שולחן העבודה (למשל "עוזר אישי") — כך העוזר ממשיך לראות גם את כל מה ש-Claude Code כבר יודע עליך.
📞 איך העוזר מחובר לוואטסאפ
🟢
כרום — חינמי
פעיל עכשיו. סריקת QR, רץ על המחשב שלך. חינם לגמרי (מתנתק לפעמים ומתחבר לבד).
🟩
Green API
יציב יותר — לא מתנתק ולא תלוי בדפדפן. ~$12/חודש. דורש חשבון ב-console.green-api.com.
🔒
ענן
שדרוג להמשך — תמיד פעיל בלי המחשב. דורש שרת בתשלום.
בקונסול של Green API: Instances ← ה-instance שלכם ← idInstance ו-apiTokenInstance. הפרטים נשמרים רק על המחשב הזה. אחרי החיבור — ה-QR יופיע במסך הראשי וסורקים אותו כרגיל.
מעבר בין דרכי החיבור מפעיל את העוזר מחדש (כמה שניות). "ענן" — שדרוג להמשך.
